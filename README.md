# Doujaboutique – maquette e-commerce

Maquette complète en un seul fichier `index.html` (HTML + CSS + JS, sans framework ni backend). Ouvrez-le directement dans un navigateur.

- Numéro WhatsApp : modifiez `const WHATSAPP_NUMBER = "212XXXXXXXXX";` en haut du script.
- Produits : tableau `PRODUITS` (nom, catégorie, prix, ancien prix, tailles, couleurs, images, badge, description).
- Frais de livraison : `FRAIS_LIVRAISON` (30 DH) et `VILLE_LIVRAISON_GRATUITE` (Fès).

## Contenu du dépôt
- `index.html` : tout le site (HTML + CSS + JS dans un seul fichier). Les images viennent d'Unsplash (en ligne).
- `screenshots/` : captures mobile et desktop de la maquette.
